# Showcase

<a href="./showcase/">Open the interactive engine laboratory.</a>

The Vanilla TypeScript + PixiJS application in `apps/showcase` runs the real fixed clock, input manager, isometric projection, camera/layer adapter, effects, diagnostics, and asset-manifest resolver. It uses only neutral generated shapes and asks for an explicit manifest base URL.

This keeps the engine website Apache-2.0 clean and independent of any game-specific art pack.
